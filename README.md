<h1> "Predictive Analysis of Loan Defaults Using Penalized Logistic Regression, Random Forest, and Gradient Boosting Models" </h1>

<h2>Description</h2>
This project analyzed loan default predictions using logistic regression, LASSO, Random Forest, and Gradient Boosting. While logistic models offered interpretability, they were outperformed by non-parametric methods. Random Forest achieved the highest accuracy (99.95%) and AUROC (0.9902), closely followed by Gradient Boosting. Across all models, historical default was the most influential predictor, confirming the superiority of machine learning models for accurate loan default classification.
